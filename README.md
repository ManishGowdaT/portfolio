# Manish Gowda T — Developer Portfolio

A bespoke, editorial-inspired personal portfolio website for **Manish Gowda T**, Full Stack Developer based in Bengaluru, India.

## Design Philosophy

- **Aesthetic**: Warm, literary, editorial design. Generous whitespace, hairline dividers, asymmetric rhythm, and large typographic contrast.
- **Palette**:
  - Warm Canvas: `#F3EFE7`
  - Deep Ink: `#16140F`
  - Muted Ink: `#6B665B`
  - Hairlines: `#D9D3C4`
  - Vermilion Accent: `#E4572E` (large display, underlines, and hover) / `#C8431D` (high-contrast small text)
  - Inverted Dark Section: `#16140F` with `#F3EFE7` ink (Projects showcase)
- **Typography**:
  - Headings: **Fraunces** Light (300) roman, tight tracking
  - Body: **Inter Tight** (400/500)
- **Zero AI Template Tells**: No neon glows, no synthetic metrics, no pseudo-terminal tags (`//`), and no 3D canvas gimmicks.

## Sections

1. **Hero**: Full-viewport display typography with clip-path mask entrance, subtitle, location, and anchored directional links.
2. **About**: Engineering philosophy, background summary, and 4 primary focus areas.
3. **Skills**: Quiet hairline-divided text rows grouped by Languages, Backend, Frontend, Databases, and Tools.
4. **Experience**: Developer Intern at Ellipsonic with role details and responsibilities.
5. **Projects** *(Inverted Dark)*: Editorial rows for **OptionAlgo**, **LexDraft**, and **Sales Forecasting System**, with expandable case study modals and screenshot placeholders.
6. **Achievements**: Hackathon, design competition, and innovation program achievements.
7. **Education**: B.E. in Information Science & Engineering, pre-university education, and certifications.
8. **Contact**: Prominent *"Let's build something together."* invitation with email, GitHub, LinkedIn, and phone links.

## Tech Stack

- **React 19** + **Vite** + **TypeScript**
- **Tailwind CSS v4** (`@tailwindcss/vite`)
- **GSAP + ScrollTrigger** (reveal choreographies & hero mask wipes)
- **Lenis** (smooth inertial scrolling, disabled on touch/reduced-motion)
- **Framer Motion** (layout transitions for project case studies)
- **Lucide Icons**

## Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Type check and build production bundle
npm run build

# Preview production build locally
npm run preview
```
